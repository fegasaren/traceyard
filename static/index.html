Traceyard Discover

Поиск и просмотр OpenTelemetry-трейсов в Tempo.

Выберите период и сервис, добавьте условия по атрибутам или напишите свой TraceQL. Поля слева открывают форму фильтра. Клик по результату откроет дерево спанов; клик по спану — его атрибуты, события и связи.

Фильтры объединяются через && и должны выполняться на одном спане. Гистограмма, медиана и другие показатели рассчитаны только по загруженной выборке. «Совп. спаны» показывает совпадения поиска, а не размер всего трейса.

Период применяется к поиску; открытие по Trace ID от него не зависит. Время отображается в часовом поясе браузера.
